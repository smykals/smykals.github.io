Cable Run

A server-room maze-and-chase game: every move extends your cable, so you collect packets, dodge rats and hazards, and reach the destination port without tangling yourself.

The Idea

Anyone who has run cable through a server room knows the path matters as much as the destination. In Cable Run, the cable you leave behind is part of the maze.

How It Plays

  1. Pick a levelUnlocked levels are saved
  2. →
  3. Run the cableEvery move extends it
  4. →
  5. Collect packetsExplore hidden aisles
  6. →
  7. Evade ratsHazards that chase you
  8. →
  9. Reach the portFinish the run

Keyboard and pointer controls; progress is stored on your device.

How It’s Built

About 1,200 lines of JavaScript drive the maze, enemy behavior, level select, pause menu and saved progress, with a separate stylesheet for the server-room look. Enemies change behavior when frightened, in the tradition of classic maze-chase games.
