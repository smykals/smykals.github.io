Packet Launcher

A physics browser game where you aim, charge and launch a packet, and network elements push it on or knock it off course.

The Idea

Getting data from one place to another is rarely a straight line. Packet Launcher turns that into physics: you fire a packet and the network around it changes where it goes.

How It Plays

  1. AimUp and down arrows
  2. →
  3. ChargeHold Space
  4. →
  5. LaunchRelease Space
  6. →
  7. TravelRepeaters bounce it on, routing boosts push it forward
  8. →
  9. ScoreDistance travelled

Pickups grow or shrink the packet; R restarts and Space pauses.

How It’s Built

The whole game lives in one HTML file of about 1,400 lines: the canvas renderer, physics loop, input handling and interface. Keeping it self-contained means it loads instantly and has nothing to install.
