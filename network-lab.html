Project 01 / Networking

Enterprise Network Lab

A hands-on infrastructure environment designed to develop, test, and document enterprise networking concepts including segmentation, switching, firewalling, virtualization integration, secure management, and structured troubleshooting.

01 / Overview

Why I built it.

The goal of this lab is to recreate core elements of an enterprise network in a controlled environment where configurations, failures, design decisions, and troubleshooting methods can be tested without affecting a production system.

Rather than focusing only on whether a configuration works, the environment is designed around segmentation, maintainability, documentation, security, and understanding how infrastructure components interact.

04 / Objectives

What the environment is designed to test.

Segmentation Separate infrastructure by function using VLAN-based network segmentation.
Switching Configure and validate access interfaces, trunking, and Layer 2 behavior.
Routing Understand traffic flow between logically separated network segments.
Security Apply firewalling and network boundaries while maintaining required connectivity.
Virtualization Integrate physical networking with virtual machines and virtual infrastructure.
Troubleshooting Intentionally create and diagnose failures using a repeatable troubleshooting process.
05 / Troubleshooting

Follow the path, not the assumption.

When connectivity fails, I work through the relevant layers systematically instead of immediately changing configurations. This helps separate symptoms from the actual point of failure.

01 Physical connectivity and device state
02 Interface configuration and operational state
03 VLAN membership and segmentation
04 Trunk configuration and VLAN propagation
05 IP addressing and subnet configuration
06 Routing and gateway reachability
07 Firewall and access-control behavior
08 Application or service connectivity

07 / Lessons

A working network isn't the finish line.

Building the environment reinforces that reliable infrastructure depends on more than achieving connectivity. Intentional segmentation, predictable addressing, documentation, visibility, and clear device roles make an environment easier to troubleshoot, secure, expand, and support.

The objective is to build systems that are not only functional, but understandable and repeatable.
