Project 01 / Networking

Enterprise Network Lab

A hands-on infrastructure environment built to develop, test, and document enterprise networking concepts including switching, segmentation, routing, firewalling, virtualization integration, secure management, and structured troubleshooting.

01 / Overview

A working multi-layer network lab.

This lab recreates core elements of an enterprise network in a controlled environment using physical Cisco switching, Fortinet firewalling, virtualization, and segmented network design.

The environment is actively used to configure and validate switching, routing, VLANs, firewall policies, management access, network services, virtualization connectivity, and troubleshooting workflows.

07 / Troubleshooting

Follow the path, not the assumption.

Troubleshooting starts by establishing what should be happening, identifying where actual behavior diverges from that expectation, and then narrowing the problem using device state and traffic-path evidence.

01 Physical connectivity and device state
02 Interface configuration and operational state
03 VLAN membership and trunking
04 IP addressing and subnet configuration
05 Gateway and inter-VLAN routing
06 DHCP and DNS behavior
07 Firewall policy and traffic flow
08 Application or service connectivity
08 / Takeaway

A working network isn't the finish line.

Building the environment reinforces that reliable infrastructure depends on more than basic connectivity. Segmentation, routing, documentation, management access, service dependencies, firewall behavior, and virtualization all affect how easy a network is to operate and troubleshoot.

The lab continues to evolve as I add new technologies, create controlled failures, and validate how changes affect the overall environment.
