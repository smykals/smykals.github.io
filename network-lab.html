Project 01 / Networking

Enterprise Network Lab

A hands-on infrastructure lab designed to develop and validate enterprise networking, segmentation, routing, firewalling, management, and troubleshooting skills.

Overview

This lab recreates core elements of a small enterprise environment using physical networking hardware, virtualization, and segmented network design. The goal is to build practical experience across switching, routing, firewalling, VLANs, management networks, and infrastructure troubleshooting.

Technologies

Fortinet FortiGate 60E • Cisco Catalyst 3560 • Cisco Catalyst 2960 • VLANs • 802.1Q • IPv4 • SSH • Proxmox • Linux • Windows

Objectives

  • Segment infrastructure using VLANs.
  • Separate management traffic from client traffic.
  • Configure and validate 802.1Q trunk links.
  • Practice secure remote device administration through SSH.
  • Integrate physical switching with virtualized workloads.
  • Develop repeatable network troubleshooting workflows.

Implementation

The environment uses Cisco switching for Layer 2 segmentation and a FortiGate firewall for network edge and routing functions. Dedicated VLANs are used to separate management, server, client, and experimental traffic.

Configuration examples shown in this portfolio are sanitized. Passwords, public IP addresses, MAC addresses, serial numbers, authentication secrets, and production information are excluded.

Example Trunk Configuration

interface GigabitEthernet0/1
 description Uplink
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30,40

Example Management Interface

interface Vlan10
 description Management
 ip address 10.13.10.2 255.255.255.0
 no shutdown

Troubleshooting Approach

Troubleshooting is performed from the lowest relevant layer upward. Physical connectivity and interface state are validated first, followed by VLAN membership, trunk configuration, addressing, routing, firewall policy, and application-level connectivity.

Lessons Learned

Building the environment reinforces that network troubleshooting becomes significantly easier when segmentation, addressing, documentation, and device roles are intentionally designed. A working configuration is only part of the objective; the environment should also be understandable, repeatable, and supportable.
