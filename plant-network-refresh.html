Supporting a Plant Network Refresh While It Runs

Supported a staged plant network refresh while maintaining production support, inside a plant that never stops producing.

Environment
Continuous-production plant
Scale
About 300 endpoints, approximately 120 access points
My role
Supported deployment and validation as the sole onsite IT engineer
Constraint
No disruption to production

The Challenge

The plant's switching and wireless infrastructure was being refreshed in stages. The network carries production systems and connected equipment, so every change had to fit around the line rather than the other way round.

How Each Change Was Run

  1. PlanApproved configuration and timing agreed around production
  2. →
  3. StageEquipment prepared with approved switchport settings
  4. →
  5. SwapOld hardware replaced during the agreed window
  6. →
  7. ValidateConnectivity confirmed for users and connected equipment
  8. →
  9. Hand backIssues followed up before closing

The same sequence was repeated for each part of the facility.

What I Did

  • Deployed and Replaced Network Equipment

    Installed new Cisco switching hardware in place of the old equipment.

  • Applied Approved Configurations

    Applied the approved switchport and network configurations, rather than improvising on live equipment.

  • Helped Roll out Wireless

    Assisted with the wireless infrastructure deployment across the facility.

  • Worked Around Production

    Coordinated timing with operations so changes landed when the line could tolerate them.

  • Validated and Troubleshot

    Confirmed connectivity after each change and resolved what didn't come back cleanly.

Results

24/7

Production environment the refresh was carried out in.

Skills Used

  • Cisco switching
  • Enterprise wireless
  • Switchport configuration
  • Change management
  • Deployment support
  • Connectivity validation
